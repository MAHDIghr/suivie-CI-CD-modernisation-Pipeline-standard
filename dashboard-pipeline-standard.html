Le chantier est structuré et entre dans la formalisation des premiers livrables. Java est le stream le plus avancé ; Node.js/NPM est en cours de définition. Priorités : finaliser la documentation Java, produire le schéma Node.js/NPM, cadrer Python et débloquer/cadrer Lambda. Les livrables minimums attendus sont un schéma visuel du pipeline et sa documentation. Les standards doivent intégrer les contrôles qualité et sécurité.
